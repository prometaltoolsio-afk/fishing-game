CASTLE GUARDIAN - WEB GAME (প্রাথমিক playable version)

চালানোর নিয়ম:
1) ZIP ফাইল Extract করুন।
2) castle_guardian_web_game ফোল্ডারের index.html ফাইল Chrome/Edge-এ খুলুন।
3) Archer / Knight / Cannon বেছে নিন।
4) গেমের মাঠে মাউস বা আঙুল দিয়ে টেনে লক্ষ্য ঠিক করুন।
5) FIRE চাপুন।
6) শত্রুদের হারালে কয়েন পাবেন। সব শত্রু শেষ হলে Next Level চাপুন।

ওয়েবসাইটে আপলোড:
- ZIP Extract করুন।
- index.html, style.css, game.js, levels.js এবং README ফাইল একই ফোল্ডারে রাখুন।
- Hosting-এর public_html বা site root-এ ফাইলগুলো আপলোড করুন।
- index.html যেন root folder-এ থাকে।

এটি প্রথম playable prototype। পরের ধাপে আসল character artwork, উন্নত physics, enemy attack animation, sound, level selection ও mobile UI উন্নত করা যাবে।
ইন্টারনেট সংযোগ বা বাইরের library লাগে না।
